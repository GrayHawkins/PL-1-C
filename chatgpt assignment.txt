 ## 1\. `struct` — creating your own data type

 So far, you've used variables like:

```
char name[50];
int id;
float grade;
```

 But imagine a student has **all three** of these pieces of information.

 A `struct` lets you group related variables together.

```
struct Student {
    char name[50];
    int id;
    float grade;
};
```

 Now you have created a new type called `struct Student`.

 You can create a student:

```
struct Student student1;
```

 And access its individual pieces using `.`:

```
student1.id = 1234;
student1.grade = 8.5;
```

 For strings:

```
strcpy(student1.name, "Gabriel");
```

 You'll need:

```
#include <string.h>
```

 ### Think of it like this

 Without a struct:

```
student1_name
student1_id
student1_grade

student2_name
student2_id
student2_grade
```

 With a struct:

```
student1
 ├── name
 ├── id
 └── grade

student2
 ├── name
 ├── id
 └── grade
```

 That's much easier to manage.

 # 2\. Arrays of structs

 This is where `struct` becomes really useful.

 You already know arrays:

```
int numbers[10];
```

 You can make an array of students:

```
struct Student students[10];
```

 Now you have space for 10 students.

 You access them using an index:

```
students[0]
students[1]
students[2]
```

 And then their properties:

```
students[0].id
students[0].grade
students[0].name
```

 For example:

```
students[0].id = 1001;
students[0].grade = 8.5;

students[1].id = 1002;
students[1].grade = 7.2;
```

 You can combine this with a loop:

```
for (int i = 0; i < 10; i++) {
    printf("%d\n", students[i].id);
}
```

 This is one of the most important concepts for your assignment.

 # 3\. Functions

 You've already used functions such as:

```
printf();
scanf();
```

 You can create your own.

 For example:

```
void sayHello() {
    printf("Hello!\n");
}
```

 Then:

```
int main() {
    sayHello();
}
```

 The advantage is that you can break a large program into smaller pieces.

 Instead of:

```
int main() {
    // 300 lines of code...
}
```

 you can have:

```
void addStudent() {
    // code for adding
}

void showStudents() {
    // code for displaying
}

void searchStudent() {
    // code for searching
}

int main() {
    // menu
}
```

 This is called **modular programming**.

---

 # 4\. Functions with parameters

 You can give information to a function.

 For example:

```
void greet(char name[]) {
    printf("Hello, %s!\n", name);
}
```

 Then:

```
greet("Gabriel");
```

 Output:

```
Hello, Gabriel!
```

 Another example:

```
void printNumber(int number) {
    printf("Number: %d\n", number);
}
```

 Then:

```
printNumber(42);
```

---

 # 5\. Functions that return values

 This is particularly important for your assignment.

 You've already seen functions that return something, even if you didn't create them yourself.

 For example:

```
int main()
```

 `main()` returns an `int`.

 You can make your own:

```
float calculateAverage(float a, float b) {
    return (a + b) / 2;
}
```

 Then:

```
float result = calculateAverage(8.0, 6.0);

printf("%.2f", result);
```

 Output:

```
7.00
```

 The important distinction is:

```
void
```

 means:

 > This function doesn't return a value.

 Whereas:

```
float
```

 means:

 > This function returns a `float`.

 So:

```
void sayHello()
```

 does something.

 But:

```
float calculateAverage()
```

 does something **and gives you a `float` back**.

---

 # 6\. Passing a struct to a function

 Now we combine concepts.

 Suppose:

```
struct Student {
    char name[50];
    int id;
    float grade;
};
```

 We can make a function that receives a student:

```
void printStudent(struct Student student) {
    printf("Name: %s\n", student.name);
    printf("ID: %d\n", student.id);
    printf("Grade: %.2f\n", student.grade);
}
```

 Then:

```
struct Student student1;

student1.id = 1001;
student1.grade = 8.5;

strcpy(student1.name, "Gabriel");

printStudent(student1);
```

 This is extremely useful because you can move the responsibility for displaying a student into its own function.

---

 # 7\. Passing an array to a function

 You can also give an array to a function.

 For example:

```
void printNumbers(int numbers[], int size) {
    for (int i = 0; i < size; i++) {
        printf("%d\n", numbers[i]);
    }
}
```

 Then:

```
int numbers[] = {10, 20, 30, 40};

printNumbers(numbers, 4);
```

 Notice that we give the function **both**:

```
numbers
```

 and:

```
4
```

 Why?

 Because C doesn't automatically give the function the number of elements in the array.

 So this:

```
printNumbers(numbers, 4);
```

 means:

 > Here's my array, and it contains 4 elements.

 # 8\. Passing an array of structs

 Now we're getting directly into your assignment.

 Suppose:

```
struct Student students[10];
```

 We can make:

```
void showStudents(struct Student students[], int count) {
    for (int i = 0; i < count; i++) {
        printf("Name: %s\n", students[i].name);
        printf("ID: %d\n", students[i].id);
    }
}
```

 Then:

```
showStudents(students, 5);
```

 means:

 > Show the first 5 students in my array.

 This lets your `main()` stay relatively clean.

 # 9\. Strings in C

 There's one important thing you need to understand before the assignment.

 C doesn't have a special built-in `string` type.

 Instead, strings are arrays of `char`.

 For example:

```
char name[50];
```

 This can store:

```
Gabriel
```

 You can read it with:

```
scanf("%49s", name);
```

 Notice something interesting:

```
scanf("%49s", name);
```

 **not**

```
scanf("%49s", &name);
```

 When using a character array as a string, the array name already represents its memory address in this context.

 There's another issue: `%s` stops at whitespace.

 So:

```
Gabriel Augusto
```

 would only read:

```
Gabriel
```

 For names, you'll eventually want to learn:

```
fgets()
```

 For example:

```
fgets(student.name, 50, stdin);
```

 We'll deal with the complications of mixing `scanf()` and `fgets()` when you reach that point.

 # 10\. Searching an array

 Your assignment asks the user for an ID and then finds the student.

 This is basically a **linear search**.

 Suppose:

```
students[0].id = 1001;
students[1].id = 1002;
students[2].id = 1003;
```

 The user enters:

```
1002
```

 You can do:

```
for (int i = 0; i < count; i++) {

    if (students[i].id == searchID) {
        printf("Student found!\n");
    }

}
```

 The program checks:

```
1001 == 1002? No
1002 == 1002? Yes!
```

 You can then use:

```
break;
```

 to stop searching.

 # 11\. A useful new pattern: `found`

 There's a very common programming pattern you'll encounter.

```
int found = 0;

for (int i = 0; i < count; i++) {

    if (students[i].id == searchID) {
        found = 1;
        break;
    }
}

if (found) {
    printf("Student found!\n");
}
else {
    printf("Student not found.\n");
}
```

 Why use `0` and `1`?

 Conventionally:

```
0 = false
1 = true
```

 Later you'll learn the C `bool` type, which makes this cleaner:

```
bool found = false;
```

 with:

```
#include <stdbool.h>
```

 # 12\. Validation

 Your ATM program had a small amount of validation:

```
if (input > currentBalance)
```

 Now we'll make validation more robust.

 For example, grades should be between 0 and 10.

 You could do:

```
do {
    printf("Enter grade: ");
    scanf("%f", &grade);

    if (grade < 0 || grade > 10) {
        printf("Invalid grade.\n");
    }

} while (grade < 0 || grade > 10);
```

 The important idea here is that the program **doesn't continue until the input is valid**.

 # 13\. Putting the concepts together

 Your eventual program will have roughly this architecture:

```
                    main()
                      |
                +-----+-----+
                |           |
              menu        students[]
                |
       +--------+---------+
       |        |         |
      add     show      search
       |        |         |
     struct   struct    linear
                        search
```

 And your data might look like:

```
struct Student {
    char name[50];
    int id;
    float grades[3];
};
```

 Then:

```
struct Student students[10];
```

 And you'll keep track of how many students actually exist:

```
int studentCount = 0;
```

 So if you've registered 3 students:

```
students[0] → Gabriel
students[1] → Maria
students[2] → João

studentCount = 3
```

 You **don't** want to loop through all 10 positions and assume they contain students.

 Instead:

```
for (int i = 0; i < studentCount; i++)
```
